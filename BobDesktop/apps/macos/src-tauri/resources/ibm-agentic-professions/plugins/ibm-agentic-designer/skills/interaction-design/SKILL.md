# Interaction design

Décrire navigation, ouverture/fermeture, sélection, états vides, chargement et erreurs avec des interactions déclaratives liées aux nœuds. Les interactions simples de l’aperçu restent locales ; ne pas demander un appel LLM pour un clic ou un changement d’onglet.
