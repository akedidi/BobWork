# Wireframe

Créer la hiérarchie, les zones, les composants et les actions dans le Design IR. Utiliser les nœuds et layouts sémantiques ; ne pas rasteriser une maquette. Le même document doit pouvoir évoluer vers une UI haute fidélité.
